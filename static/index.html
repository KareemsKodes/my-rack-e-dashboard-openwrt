Flash drive workflow

  1. Download conversion bundle for the selected profile.
  2. Format a removable USB as FAT32 + MBR and name it MX65FLASH.
  3. Copy bundle files and verify them against SHA-256.
  4. Read READ_ME_FIRST_MX65.txt before using the USB on the router.

After flashing the MX65

When OpenWrt boots, keep the laptop directly connected and check:

ping 192.168.1.1

Then complete in order:

  1. Set root password and confirm /etc/openwrt_release.
  2. From the same macOS machine, run install-and-activate.sh.
  3. Open http://192.168.1.1/mx65/, save the token, then click Check.
  4. Open Setup Console for HTTPS trust, Cloudflare Tunnel, backups, and firewall hardening.

Direct connection: use a LAN port and keep the MX65 off the home LAN/WAN path until installation is complete.
