# Naming and Trademark Boundaries

This page is practical project guidance, not legal advice.

## Project Name

`My-Rack-E Dashboard` is an independent rack/lab name for an OpenWrt dashboard that repurposes previously unsupported or dashboard-incompatible MX appliances.

The project must not present itself as Cisco Meraki, an official vendor dashboard, or a Cisco-supported firmware path.

## Risk Check

`My-Rack-E Dashboard` is visually separated from the vendor mark, but it remains a hardware-adjacent project for Cisco Meraki appliances. Noncommercial status explains the project context, but it does not remove trademark confusion risk by itself.

Risk reducers used in this repository:

- Prominent disclaimer that the project is not affiliated with, endorsed by, or sponsored by Cisco Meraki.
- No Cisco or Meraki logos.
- No claim of official compatibility, certification, or support from Cisco.
- No copied vendor dashboard assets.
- Independent-project wording rather than official replacement language.
- Clear description of unsupported-hardware reuse through OpenWrt.

For the lowest naming risk before public release, use a name that is less visually and phonetically close to `Meraki`.

Avoid:

- using Cisco or Meraki logos
- registering a domain that looks official
- naming releases as official vendor firmware
- using Cisco/Meraki marks more than needed to identify the original hardware
- marketing the UI as a clone

## Repository Disclaimer

Use this wording in public-facing package text:

> My-Rack-E Dashboard is an independent OpenWrt-powered management interface for compatible Cisco Meraki MX appliances that are no longer usable with the manufacturer's supported dashboard path. It provides a local firewall-management interface for lab reuse of otherwise idle hardware.
